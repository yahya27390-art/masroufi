# تطبيق مصروفي (Masroufi Finance) 💰✨

نظام عصري واحترافي لإدارة المصروفات الشهرية والالتزامات الثابتة وتحويل العملات والتحليلات المالية.

---

## 🌟 الميزات الرئيسية للنظام

1. **إدارة المصروفات الشهرية (Monthly Expenses):**
   - تسجيل فوري للمصروفات مع تحديد التصنيف، طريقة الدفع (كاش، فيزا/مدى، تحويل بنكي، محفظة إلكترونية)، والملاحظات.
   - دعم كامل لتسجيل أي مصروف بعملة أجنبية مع تحويله تلقائياً للعملة الأساسية.
   - فلترة ذكية، بحث سريع، وترتيب حسب التاريخ أو المبلغ.

2. **إدارة الثوابت والالتزامات الدورية (Fixed Commitments):**
   - قسم مخصص للالتزامات الشهرية المتكررة (إيجار السكن/المكتب، فواتير الكهرباء والإنترنت، أقساط القروض والسيارات، اشتراكات البرامج).
   - تحديد يوم الاستحقاق الشهري (1 - 31).
   - **زر سداد بضغطة واحدة:** تأكيد سداد الالتزام لهذا الشهر بضغطة زر ليتحول تلقائياً إلى مصروف فعلي مسجل وتحديث حالة الالتزام إلى "تم السداد ✓".

3. **محول ومسعر العملات المتعدد (Multi-Currency Engine):**
   - دعم العملات الرئيسية: ريال سعودي (SAR)، دولار (USD)، جنيه مصري (EGP)، يورو (EUR)، درهم إماراتي (AED)، دينار كويتي (KWD)، وغيرها.
   - حاسبة تحويل سريعة وفورية بين أي عملتين.
   - إمكانية تحديث أسعار الصرف آلياً بضغطة زر من خادم العملات المباشر، أو تعديلها يدوياً.
   - إمكانية تغيير العملة الأساسية للنظام في أي وقت.

4. **لوحة التحليلات والرسوم البيانية (Visual Analytics):**
   - رسم بياني دائري (Donut Chart) يوضح نسب الإنفاق لكل تصنيف.
   - مسار الصرف اليومي (Bar Chart) لتتبع حركة الإنفاق على مدار أيام الشهر.
   - بطاقات إحصائية: إجمالي المصروفات، الثوابت المستحقة، معدل الصرف اليومي، ووضع الميزانية.

5. **الميزانية الشهرية والتقارير والتصدير (Reports & Export):**
   - تحديد سقف الميزانية التقديرية مع شريط استهلاك ملون وتنبيهات عند الاقتراب أو التجاوز.
   - تصدير كشوف المصروفات إلى ملفات Excel (`.xlsx`) معقمة بالكامل ضد ثغرات Formula Injection.
   - طباعة كشف مالي رسمي A4 بضغطة زر (Print-ready).
   - ميزة النسخ الاحتياطي الكامل (JSON Backup & Restore) لحفظ أو نقل البيانات بسهولة.
